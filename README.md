# LoR (Loop of Resilience)

A modular engineering verification system for OpenClaw.

## Installation
Run the setup script to initialize:
```bash
./scripts/setup.sh
```

## Structure
- `engine/`: Core logic modules.
- `tests/`: Automated verification tests.
- `SKILL.md`: Skill definition and configuration.

## Usage
`@[AgentName] /lor [task]` to trigger the verification loop.
